# Численное моделирование мертвой петли (Dead Loop)

Полное численное моделирование движения материального тела по вертикальной дуге кольца (мертвой петле) с учетом силы трения. Проект включает моделирование, анализ результатов и визуализацию.

## Описание задачи

**Мертвая петля** — классическая задача механики, в которой тело движется по вертикальной окружности под действием силы тяжести и силы реакции опоры.

### Исходные параметры (вариант 1)
- Масса тела: **m = 1 кг**
- Радиус кольца: **R = 5 м**
- Угловой размер дуги: **α = 120°** (π/2 + π/6 рад)
- Коэффициент трения: **μ = 0.01**
- Ускорение свободного падения: **g = 9.81 м/с²**

### Цели моделирования
1. Определить **минимальную начальную скорость** для прохождения всей дуги
2. Построить **траекторию движения** по дуге и после отрыва
3. Провести **энергетический анализ** движения
4. Исследовать **зависимость результатов** от параметров задачи

## Основные результаты

### Минимальная начальная скорость
```
v₀_min = 13.322 м/с
```

При этой скорости тело проходит всю дугу α = 120° и отрывается в верхней части с параметрами:
- Угол отрыва: **θ ≈ 120.05°**
- Скорость в момент отрыва: **v ≈ 4.96 м/с**
- Координаты отрыва: **x ≈ 4.33 м, y ≈ 7.50 м**

- Потеря механической энергии на трение: **≈ 2.5 Дж**
- Доля энергии на трение: **≈ 15-20% от начальной кинетической энергии**

## 🔬 Физическая теория

### Силы, действующие на тело

В произвольной точке дуги с углом θ от нижней точки:

**Сила тяжести:**
```
F_g = mg (вертикально вниз)
```

**Нормальная реакция опоры:**
```
N = m·v²/R + mg·cos(θ)
```

**Сила трения:**
```
F_тр = μN (против движения)
```

### Условие прохождения петли

 **Важно:** Формула `mg = m·v²_min/R` справедлива **только для верхней точки полного кольца** (θ = π).

Для произвольной дуги используется энергетический подход с численным моделированием.

### Уравнения движения

Система дифференциальных уравнений:

```
dv/dt = -g·sin(θ) - (μ/m)·(m·v²/R + mg·cos(θ))
dθ/dt = v/R
```

Начальные условия: `θ(0) = 0`, `v(0) = v₀`

## Интерпретация результатов

### Ключевые выводы

1. **Минимальная скорость зависит от:**
   - Радиуса кольца R
   - Углового размера дуги α
   - Коэффициента трения μ

2. **Влияние трения:**
   - Значительно увеличивает требуемую начальную скорость
   - Приводит к потере 15-20% начальной кинетической энергии
   - Монотонно уменьшает скорость при движении вверх

3. **Отрыв от дуги:**
   - Происходит, когда нормальная реакция N = 0
   - Зависит от начальной скорости и геометрии дуги
   - При увеличении начальной скорости точка отрыва смещается
